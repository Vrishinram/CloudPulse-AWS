# ⚡ CloudPulse-AWS

> **The Ultimate AWS re/Start Knowledge Check & Cloud Exam Mastery Platform**  
> 588+ Interactive Questions • 96 Curated Topics • Multi-Select Validation • Offline PDF Study Booklet Exporter

---

## 🌟 Overview

**CloudPulse-AWS** is a modern, high-performance examination and revision platform designed for learners preparing for the **AWS Certified Cloud Practitioner (CLF-C02)** and the **AWS re/Start** curriculum.

Built with Next.js 15, React 19, Tailwind CSS, Lucide icons, and client-side vector PDF generation, it delivers an intuitive, distraction-free environment to practice, test, and master all cloud concepts.

---

## ✨ Features

- 🎯 **Complete AWS re/Start Curriculum**: Covers all **96 Knowledge Check modules** with **588 verified questions** spanning compute, networking, storage, security, databases, serverless, and cloud economics.
- 🧩 **Multi-Select Question Engine**: Accurately mirrors real exam formats with multi-choice prompts (`Select TWO`, `Select THREE`) featuring interactive checkbox toggling and precise answer validation.
- 💡 **Instant Explanations & Domain Context**: Every question includes detailed curriculum-aligned explanations clarifying why correct answers are right and why distractors are incorrect.
- 📄 **Offline PDF Study Guide Exporter**: 
  - Generate clean, multi-page vector PDF study booklets directly in the browser via `jsPDF`.
  - Export the entire **588-question question bank** or target specific modules/topics.
  - Formatted with visual answer keys (`[✓]`), distinct green highlights, and expandable explanation boxes.
- 🎨 **Modern Dark Glassmorphism UI**: Polished aesthetic with real-time score indicators, topic filtering, and responsive mobile-first layout.
- ⚡ **Zero-Latency Client Architecture**: Instant feedback and offline-ready performance.

## 🚀 Getting Started

### Prerequisites
- Node.js 18.x or higher
- npm, yarn, or pnpm

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Vrishinram/CloudPulse-AWS.git
   cd CloudPulse-AWS
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Open in browser**:
   Navigate to [http://localhost:3000](http://localhost:3000).
